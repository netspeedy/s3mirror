## Usage

```bash
s3mirror [-c FILE] [-w N] [--no-delete] [-q] [-d] [-l FILE]
s3mirror -c FILE --show-config
s3mirror --version
```

s3mirror takes no positional arguments; everything it mirrors is in the config file. Each run
mirrors every source bucket that isn't excluded, and there are no flags to pick buckets, prefixes
or objects.

## Flags and the config

Only two settings can be changed from the command line, and both win over the config for that run:
`--workers` sets `performance.max_workers`, and `--no-delete` sets `sync.delete_extraneous` to
`false`. Everything else, including the endpoints and `exclude_buckets`, comes from the file.

## Errors

An unknown flag, a missing value or a `--workers` value that isn't a positive whole number prints
usage and the problem to standard error and exits 2, before anything else happens:

```text title="Output"
usage: s3mirror [-h] [-c FILE] [-q] [-d] [-l FILE] [-w N] [--no-delete]
                [--show-config] [--version]
s3mirror: error: argument -w/--workers: must be greater than zero
```

[Exit codes](/s3mirror/reference/exit-codes/) has every code s3mirror exits with.

## `--help`

```text title="Output"
usage: s3mirror [-h] [-c FILE] [-q] [-d] [-l FILE] [-w N] [--no-delete]
                [--show-config] [--version]

S3 Bucket Mirror - Professional bucket synchronization

options:
  -h, --help           show this help message and exit
  -c, --config FILE    Configuration file path (.yaml, .yml or .json)
  -q, --quiet          Quiet mode - only errors (for cron)
  -d, --debug          Debug mode - verbose output
  -l, --log-file FILE  Log to file (console shows only errors unless --debug
                       specified)
  -w, --workers N      Number of parallel workers (default: max_workers, 20 if
                       unset)
  --no-delete          Don't delete extraneous files from destination
  --show-config        Display configuration and exit
  --version            show program's version number and exit

Examples:
  # Normal operation (console output)
  s3mirror --config /etc/s3mirror.yaml

  # Try it first without deleting anything, showing every decision
  s3mirror --config /etc/s3mirror.yaml --no-delete --debug

  # Silent mode for cron
  s3mirror --config /etc/s3mirror.yaml --quiet

  # Log to file (only errors on the console, everything in the file)
  s3mirror --config /etc/s3mirror.yaml --log-file /var/log/s3mirror.log

  # Log to file with debug console output too
  s3mirror --config /etc/s3mirror.yaml --debug --log-file /var/log/s3mirror.log
        
```

From a checkout, or in the container, the program name in the help is `s3mirror.py`.
